# v0.7.0 backend CI hotfix

GitHub Actions run #19 reached the complete backend pytest suite. 103 tests passed and
two stale historical release assertions failed because legacy files
`test_v061_autopilot_contract.py` and `test_v062_autopilot_contract.py` still asserted
that the active release must be 0.6.2.

Those files are now historical feature-contract tests only. Their valid scheduler,
payment-path, Today UI, Daily Briefing, and timezone assertions remain. Current release
version assertions live only in `test_v070_autopilot_contract.py`.

This prevents a historical test filename from pinning future releases to an old version.
