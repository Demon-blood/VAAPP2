# v0.8.0 Kraken Personal Funding Guard

Kraken EUR investment funding is fail-closed to Personal money.

## Enforced before payment intent creation

- source `BankAccount.account_scope` must be `personal`;
- source `BankConnection.psu_type` must be `personal`;
- source account must be EUR and payment-enabled;
- Pro/business/corporate sources are rejected;
- the user must complete a one-time confirmation that the Kraken beneficiary name
  matches the holder name on their Personal source bank account;
- the Kraken deposit reference is optional because personal dedicated Banking Circle
  IBANs may legitimately require no reference.

The code does not hard-code any personal recipient name, IBAN, BIC, or account
identifier. Those remain runtime configuration.

The current banking data model does not expose a reliable account-holder-name field.
Therefore the automated ownership boundary is the authenticated Personal PSU consent
plus Personal account scope, reinforced by the one-time holder-name confirmation.
