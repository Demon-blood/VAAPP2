# v0.8.1 Dedicated Investments Dashboard

Money now has a dedicated **Investments** tab between Budget and Receipts.

The dashboard reads the existing Revolut Securities investment evidence plus live Kraken API balances when configured. It shows:

- total statement-backed Revolut value by currency;
- separate Brokerage and Robo portfolios;
- cash and largest current positions;
- realised P&L, net investment income and withholding tax;
- learned Revolut contribution amounts and last observed funding;
- live Kraken non-zero balances with best-effort EUR market valuation;
- Kraken funding/trading policy and latest funding state;
- Personal-only Kraken funding guard.

Revolut continues to execute its own scheduled portfolio contributions. The VA forecasts/funds those contributions and reconciles them as `investment_contribution`, not lifestyle spending.

Kraken EUR values are estimates from Kraken's public ticker. Unsupported assets remain visible without a guessed valuation.

Current position/cash snapshots are only replaced by an equal-or-newer statement period, so importing an older historical statement later cannot roll the dashboard back to stale holdings.
