# v0.7.2 Money overview hotfix

The v0.7.2 historical-finance evidence tuple gained an `is_refund` field.
`finance_overview()` still unpacked the older five-field tuple, causing both
`GET /api/finance/overview` and `GET /api/finance/budgets` to return HTTP 500.

The overview now aggregates the six-field tuple through a pure helper and applies
refunds against category spending rather than counting refunds as income.
