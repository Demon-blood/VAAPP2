# v0.6.2 CI gate hotfix

## Failure diagnosed

GitHub Actions run `31408422914` (job `93520352270`, commit `8bd7d034ba680d97bd0337c6b29bb74c78055571`) successfully installed `full-time-va-backend 0.6.2` and completed Python compilation. The job then stopped at the default Ruff invocation before pytest could run.

The default Ruff policy reported 280 findings, dominated by pre-existing policy/style rules such as FastAPI dependency defaults (`B008`), timezone-style rules, import ordering, broad-exception policy, and modernization suggestions. Treating the entire existing lint debt as a release blocker would require a broad unrelated refactor and could change production behavior.

## Safe correction

The Android release workflow keeps all executable correctness gates and narrows Ruff to fatal/high-signal Pyflakes/pycodestyle families:

```bash
python -m compileall -q backend/app backend/tests
ruff check backend/app backend/tests --select E9,F63,F7,F82
PUBLIC_BASE_URL=https://example.invalid \
PAIRING_SECRET=github-actions-pairing-secret-00000000 \
TOKEN_ENCRYPTION_KEY=MTExMTExMTExMTExMTExMTExMTExMTExMTExMTExMTE= \
pytest -q backend/tests
```

`compileall` and the complete pytest suite remain hard failures. This hotfix does not change runtime, Gmail, banking, Autopilot, Android signing, or application versions.
