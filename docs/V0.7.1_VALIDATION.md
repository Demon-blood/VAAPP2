# Full-Time VA v0.7.1 validation record

## Release identity

- Backend: `0.7.1`
- Android: `0.7.1+29`
- APK: `Full-Time-VA-Android-v0.7.1.apk`

## Statement parser evidence

The deterministic Beobank parser was exercised against six user-supplied Beobank GO statements covering statement numbers 001 through 006. The PDFs themselves are not included in this source package. Across those six statements the parser extracted 537 transactions with contiguous transaction sequences, exact credit/debit totals, exact opening/closing arithmetic, and a continuous month-to-month balance chain. Regression fixtures included in the repository are synthetic and contain no real customer identifiers.

The parser also has a synthetic negative test proving an off-by-one-cent closing balance is rejected rather than learned.

## Local gates

Packaging validation includes Python `compileall`, focused source/policy release contracts, native-PDF parser validation, workflow YAML parsing, shell syntax checks, release-marker checks, privacy scans, and archive integrity.

This packaging environment does not contain `aiosqlite`, Flutter/Dart, or the Android SDK and cannot install missing packages from the network. Therefore the complete database-backed pytest suite, `flutter analyze`, `flutter test`, Gradle compilation and signed APK build are not claimed as locally passed.

The included GitHub Actions workflow is the authoritative dependency-backed release gate. It installs `backend[dev]`, runs Python compilation, Ruff correctness rules, the full pytest suite, installs Flutter 3.38.7, resolves Android dependencies, runs `flutter analyze --no-fatal-infos` and `flutter test`, builds the signed release APK, hashes it and publishes only after preceding gates succeed.

## Financial safety boundary

Imported documents can influence learned budgeting only after statement reconciliation. They do not bypass existing payment/transfer rules, account payment enablement, cash floors, daily/monthly limits, idempotency, source-account locking, provider ambiguity quarantine or bank-required SCA.
