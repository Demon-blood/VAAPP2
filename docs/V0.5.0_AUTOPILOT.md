# v0.5.0 Autopilot deployment notes

> **Current source note:** v0.7.2 builds on this Autopilot release with financial-document correctness, Gmail lifecycle management, Daily Intelligence, communications Autopilot, budgeting, guarded own-account transfers, and verified historical bank-statement learning. The current Android artifact is v0.7.2.

This source tree is a direct upgrade of the supplied v0.4.17 archive.

## Database

Startup uses the existing SQLAlchemy `metadata.create_all()` path. v0.5.0 adds only new tables and does not rename or drop existing tables:

- `workflow_runs`
- `workflow_jobs`
- `workflow_job_dependencies`
- `operation_preferences`

Existing OAuth connections, Gmail data, bills, creditors, bank connections/accounts, payments, tasks, documents, contacts, connectors and runtime settings remain in their existing tables.

## New authenticated API

- `GET /api/autopilot/health`
- `GET /api/autopilot/briefing`
- `GET /api/autopilot/profile`
- `PUT /api/autopilot/profile/preferences/{domain}/{preference_key}`
- `POST /api/autopilot/intents`
- `GET /api/autopilot/jobs`
- `GET /api/autopilot/workflows`
- `POST /api/autopilot/jobs/{job_id}/requeue`

## Release gate

Push the complete source tree to `main`. Because real `backend/**` and `android/**` files are changed, the included GitHub Actions push trigger will run automatically. The workflow tests the backend, installs Flutter, runs analysis/tests, builds the signed `Full-Time-VA-Android-v0.9.0.apk`, and publishes it as a prerelease when successful.
