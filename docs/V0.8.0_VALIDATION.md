## v0.8 finance safety gates

- Personal Revolut is a controlled `spending` destination, not a savings account.
- Revolut Pro is a Pro-scoped operating account when provider metadata identifies the Pro product; bank sync preserves an explicit Personal/Pro scope chosen in Money → Accounts.
- Revolut Pro is not treated as Revolut Business merely because it is used professionally.
- Child support, housing contributions and other recurring obligations can be learned and protected before surplus is moved.
- Revolut portfolio cash movements are classified as `investment_contribution`, not lifestyle spending.
- Cross-scope own-account movements are classified as owner draw/contribution and excluded from ordinary budget spend/income.
- Kraken investment funding is disabled by default and requires a verified recipient, IBAN, deposit reference, monthly target and API credentials.
- Kraken trading is disabled by default and additionally requires the configured trading permission.
- Kraken withdrawal execution is not implemented.
- Payment/funding intents are persisted before irreversible provider calls; ambiguous network outcomes block automatic retry.
