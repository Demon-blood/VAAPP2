## Tests not executable in this packaging container

The local environment does not contain `aiosqlite`, `google-api-python-client`, `asyncpg`, Ruff, Flutter, or an Android SDK platform jar, and it has no network access to install them. Therefore this document does **not** claim the complete dependency-backed pytest suite, Ruff, `flutter analyze`, `flutter test`, Gradle compilation, or signed APK build passed locally.

The included GitHub Actions workflow remains the authoritative full gate: it installs backend dependencies, runs compile/Ruff correctness checks and the complete backend pytest suite, installs pinned Flutter 3.38.7, runs `flutter analyze --no-fatal-infos`, `flutter test`, builds the signed release APK, verifies the artifact, and publishes only after all prior steps succeed.

If that full CI gate exposes a platform/compiler defect, the release should not be treated as successful until that exact failure is corrected. This is preferable to weakening the gate.

## Additional financial safety gate

- Bill-payment and own-transfer execution both use the shared effective available balance.
- Locally committed outflows remain reserved until a newer bank balance sync confirms them.
- Budget destination planning counts committed incoming own-account transfers to prevent target over-funding.
- Payment and transfer source-account rows are serialized at the irreversible execution boundary.

- A watchdog converts stale `creating` payment/transfer intents to `creation_uncertain`, blocks retry, and creates reconciliation work.
- Automatic own-account transfers retain a configurable global operating cash floor (default EUR 1,000) in addition to account-specific reserves.

- Flutter analysis remains blocking for analyzer warnings/errors; info-only style lints use `flutter analyze --no-fatal-infos` so they cannot abort a release before tests/build.
